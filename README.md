# oaxaca-twofold-lee

Twofold Oaxaca–Blinder decomposition with a Lee (1983) polychotomous selection
correction, for Stata.

`oaxaca_twofold_lee_v2` decomposes the gap in a mean outcome between two groups
when the outcome is observed only for individuals who select into one of
several mutually exclusive states. The first stage is a multinomial logit over
those states; the Lee correction term enters each group's outcome equation as a
control function; and the selectivity contribution is reported as a component
of its own rather than being folded into the explained or unexplained parts.

The command is a wrapper around `selmlog` (Bourguignon, Fournier and Gurgand,
2007). It does not re-implement the two-step estimator: it calls `selmlog` once
per group, extracts the coefficient blocks and the covariate means, and
assembles the decomposition and its delta-method variances.

## Description

| Component | Expression |
|---|---|
| `Difference` | `Ybar(ref) - Ybar(other)` |
| `Endowments` | `(Xbar_ref - Xbar_other)' beta_ref` |
| `Returns` | `Xbar_other' (beta_ref - beta_other)` |
| `Selectivity` | `theta_ref*hbar_ref - theta_other*hbar_other` |
| `WageOffers` | `Xbar_ref'beta_ref - Xbar_other'beta_other` |

The first four are the noncommittal decomposition of Neuman and Oaxaca (2004)
and add up exactly to the observed gap. `WageOffers` is what remains once the
selectivity term is netted out: the gap that would prevail in the absence of
differential selection. The two are linked by the identity
`WageOffers = Difference - Selectivity`, which the command checks and reports.

Here `theta = rho * sigma` is the coefficient on the Lee correction term and
`hbar` its mean in the corresponding cell.

## Installation

```stata
net install oaxaca_twofold_lee_v2, from("https://raw.githubusercontent.com/USER/oaxaca-twofold-lee/main") replace
```

## Requirements

Stata 16 or later, and `selmlog`:

```stata
findit selmlog
```

## Usage

```
oaxaca_twofold_lee_v2 depvar indepvars [if] [in] [aw pw fw],
        by(groupvar) select(zvarlist)
        [ ref(#) status(name) genpfx(name) innerboot(#)
          nowls vrobust nodetail ]
```

### Restricting the estimation sample

`depvar` must be missing outside the state of interest, and the estimation
sample must retain all three states. Do **not** restrict with
`if status_var == 1`: the first stage needs the individuals who did not select
into that state in order to identify the correction. Restrict through the
dependent variable instead:

```stata
gen double dep_formal = ln_wage if status_var == 1
oaxaca_twofold_lee_v2 dep_formal $x_ols, by(sex) select($z) ref(0) nowls vrobust
```

The command stops with an informative error if `status()` takes fewer than
three values in the sample.

### Options

| Option | Description |
|---|---|
| `by(varname)` | Grouping variable. Required. Must take exactly two values in the sample. |
| `select(varlist)` | Regressors of the first-stage multinomial logit. Required. |
| `ref(#)` | Value of `by()` whose wage structure is the reference. Defaults to the second level, with a note printed. |
| `status(name)` | State variable for the first stage. Default `status_var`. Must take three values. |
| `genpfx(name)` | Prefix for the correction terms generated by `selmlog`. Default `_h`. |
| `innerboot(#)` | Passes `bootstrap(#)` to `selmlog`. |
| `nowls` | OLS second stage instead of the weighted default. Recommended: it makes the accounting closure exact. |
| `vrobust` | Heteroskedasticity-robust variance, obtained by refitting the second stage with `regress, robust`. Implies `nowls`. The point estimates are unchanged. |
| `nodetail` | Suppresses the per-covariate detail matrix. |

### Stored results

Matrices: `e(b)` with the five components, `e(se_delta)` with their standard
errors, and `e(detailed)` with the endowment and returns contribution of each
covariate.

Scalars: `e(closure)` and `e(closure2)`, the two correctness checks;
`e(N_ref)` and `e(N_other)`; `e(theta_ref)`, `e(theta_oth)`, `e(hbar_ref)`,
`e(hbar_oth)`, `e(rho_ref)`, `e(rho_oth)`; and `e(var_diff)`.

Macros: `e(ref)`, `e(other)`, `e(secondstep)`, `e(vcetype)`, `e(cmd)`.
